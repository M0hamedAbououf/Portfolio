# Portfolio project notes

This branch is not the website. It holds the notes and design work for the portfolio, kept apart from the site code on `main`.

| File | What it is |
|---|---|
| `PROJECT-SUMMARY.md` | Everything done on the rebuild, every decision, how it is set up and what is left to do |
| `PROJECT-SUMMARY.pdf` | The same summary as a PDF |
| `themes/mood-3.html` | The four design looks: A bronze (the live one), B green, C periwinkle, D navy and champagne |
| `themes/fonts.html` | Title font options shown with Lato |
| `themes/arabic-compare.html` | Formal Arabic compared with Egyptian Arabic |
| `themes/shots/` | Pictures the theme pages use |
| `design/PRODUCT.md` | Who the site is for, what it must do, brand rules |

To view a theme page, download this branch and double-click the file. The `shots` folder must stay next to it. In `mood-3.html` the arrows at the bottom switch between the four looks.

Other branches: `main` is the live site (https://mohamed-abououf-portfolio.vercel.app), `old-portfolio` is the previous site.
